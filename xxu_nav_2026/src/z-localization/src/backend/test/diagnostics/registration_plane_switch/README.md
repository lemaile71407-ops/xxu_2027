# 对应平面切换回归输入

状态：保留的录包专项诊断，独立于默认 CMake 回归。这里的六项测试来自旧步长候选；当前组合候选有四项与旧断言不一致，用户已接受为继续隔离联调的已知限制，失败结果仍保留。最新在线六轮结果与具体差异统一见阶段三报告。

显式执行（加载现有 ROS/工作空间及项目依赖库环境后）：

```bash
python3 src/z-localization/src/backend/test/diagnostics/registration_plane_switch/run.py \
  --build-dir build/backend \
  --experimental \
  --output-dir log/registration_diagnostics_new_run
```

链接当前构建的后端核心；`--experimental` 显式选择已整合的组合候选，省略时检查默认算法。保留的 `--solver-object` 仅供同一头文件与 ABI 下构建的隔离对象，不能直接链接旧日志对象。脚本不会改写业务源码、安装目录或默认测试目标。输出目录必须为新目录，XML、日志及输入哈希写入其中，断言失败时如实返回非零。历史日志中的旧源码路径只说明当时位置，当前入口为本目录的 `registration_test.cpp`，点云和初值集中在 `data/`。

来源：2026-11-10 自建地图固定出生点原地转 180° 的隔离仿真录包。`oscillating_source.pcd` 是首次失信配准的最终已对齐源点云，`stable_source.pcd` 是前一成功配准的最终源点云；二者共用 `target.pcd`，均转回参考关键帧 7 坐标系。它们只支持最终状态重求解，不代表从原始初值开始的完整后端回放，也不提供真值配准变换。

使用新图专用的原配准参数：体素 0.1 m、迭代上限 16、对应距离 1 m、Huber 0.25 m，其余值见回归测试。原算法在失败输入上反复跳动约 8.33 mm，增加到 64 次迭代仍未通过原有 5 mm / 0.1° 最终步长判据；前一成功帧只需一次求解。

`reversing_source.pcd`、`reversing_target.pcd` 来自同日首版循环检测候选的后续失败录包，位于参考关键帧 6 坐标系。该样本的更新并不精确形成两状态闭环，首版检测未触发；原最终完整平移步长约 28.31 mm。它用于防止仅解决精确两状态循环的回归。

`bounded_source.pcd`、`bounded_target.pcd` 来自方向反转阻尼候选的再次失败录包，同样位于关键帧 6 坐标系。同输入最终状态重算中，迭代曾满足原最终判据，继续更新后又离开接受范围；样本用于验证预算耗尽后仍能返回已通过完整步检查的阻尼状态。该回退仅在最终状态不合格时使用，不能以直接早停降低重定位精度。

`exact_source.pcd`、`exact_target.pcd` 和 `exact_initial.txt` 来自原算法在线首次失败时的求解入口，保留真实源点云、目标点云和原始初始变换；它们支持从真实初值完整重算，不能用前述最终状态重求解替代。原算法在预算 16 时复现在线 RMSE 0.0590268865354 m 和 1066 个支撑点，增至 64 次仍未收敛。
