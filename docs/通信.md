# 上位机与 STM32 底盘通信协议

版本：v0.2 草案，待与固件确认。

## 1. 通信参数

| 项目 | 约定 |
| --- | --- |
| 通信方向 | 双向 |
| 传输方式 | USB CDC 或 UART，按硬件确定 |
| UART 参数 | 115200 bit/s、8 数据位、1 停止位、无校验、无流控 |
| 字节序 | 小端 |
| 命令频率 | 50 Hz |
| 状态频率 | 50 Hz，状态变化可立即发送 |
| 指令超时 | 150 ms |
| 线速度单位 | 0.001 m/s，使用有符号 16 位整数 |
| 角速度单位 | 0.001 rad/s，使用有符号 16 位整数 |
| 坐标系 | 底盘本体坐标系：X 向前、Y 向左、Z 向上 |

## 2. 通用帧

所有多字节整数使用**小端**；所有长度均为字节数。CRC16/MODBUS：初值 `0xFFFF`，反射多项式 `0xA001`，无最终异或，覆盖从第一个帧头字节到载荷末字节，校验值低字节先发。`Payload` 最大 64 字节，超过则丢弃并重新同步。

| 偏移 | 长度 | 字段 | 值/含义 |
| --- | ---: | --- | --- |
| 0 | 2 | `SOF` | `AA 55` |
| 2 | 1 | `version` | `02` |
| 3 | 1 | `type` | `0x10` 底盘速度命令；`0x20` 底盘状态与可选轮式里程计速度反馈 |
| 4 | 2 | `seq` | 发送端递增的 `uint16`，溢出后从 0 继续；用于诊断和状态回显 |
| 6 | 1 | `length` | 载荷长度，`uint8` |
| 7 | N | `Payload` | 按 `type` 解释 |
| 7+N | 2 | `CRC16` | 小端，覆盖前面全部 `7+N` 字节 |

接收端先查帧头、版本、类型和长度，再查 CRC；坏帧不得更新控制指令或通信保活时间。流式解析按帧头重新同步，不假设一次读操作恰好得到完整帧。未知版本、类型或不符长度直接丢弃并计数。

## 3. 上位机 → STM32：底盘速度命令 `type=0x10`

固定 `length=7`，发送频率 **50 Hz**。上位机发送底盘本体坐标系中的目标速度 `vx、vy、wz`，STM32 负责运动学解算及四轮电机控制。

速度编码采用就近取整：`vx、vy` 乘以 1000 转为 `int16`，`wz` 乘以 1000 转为 `int16`。非有限数或超出 `int16` 可编码范围的输入无效。

| 载荷偏移 | 长度 | 字段 | 含义 |
| --- | ---: | --- | --- |
| 0 | 1 | `mode` | `0` 停车，`1` 执行目标底盘速度；其他值无效 |
| 1 | 2 | `vx` | 前后线速度，`int16 × 0.001 m/s`，向前为正 |
| 3 | 2 | `vy` | 左右线速度，`int16 × 0.001 m/s`，向左为正 |
| 5 | 2 | `wz` | 底盘旋转角速度，`int16 × 0.001 rad/s`，从上方俯视逆时针为正 |

`mode=0` 时 `vx、vy、wz` 必须全为零。目标速度全零、上游指令超时或无效时，上位机发送零速停车帧；只对有效的新鲜非零指令发送 `mode=1`。不得重复发送过期的非零指令。`seq` 用于诊断和回显。

## 4. STM32 → 上位机：底盘状态与可选轮式里程计速度反馈 `type=0x20`

固定 `length=14`，发送频率 **50 Hz**，状态变化时可立即发送。状态和命令序号必须回传；轮式速度可选，仅用于联调观察，不作为主定位输入。

轮式速度由四轮编码器实测转速解算，坐标系与命令一致，不得用目标速度代替。未启用或测量无效时，清零 `bit5`、三个速度和采样时间，状态帧照常发送；上位机不得将这些零值当作静止测量。

| 载荷偏移 | 长度 | 字段 | 含义 |
| --- | ---: | --- | --- |
| 0 | 2 | `status` | `uint16` 位域：bit0 就绪，bit1 运行使能，bit2 急停，bit3 驱动故障，bit4 通信超时，bit5 轮式里程计速度反馈有效（可选）；其余保留为 0 |
| 2 | 2 | `last_seq` | 最近接受的底盘速度命令序号，`uint16` |
| 4 | 2 | `vx_measured` | 编码器解算的底盘前后线速度，`int16 × 0.001 m/s`；`bit5=0` 时填 0 |
| 6 | 2 | `vy_measured` | 编码器解算的底盘左右线速度，`int16 × 0.001 m/s`；`bit5=0` 时填 0 |
| 8 | 2 | `wz_measured` | 编码器解算的底盘旋转角速度，`int16 × 0.001 rad/s`；`bit5=0` 时填 0 |
| 10 | 4 | `sample_time_ms` | 本次轮式里程计估计的采样时刻，使用 STM32 启动后的单调毫秒计数，`uint32`，可回绕；`bit5=0` 时填 0 |

速度和采样时间须对应同一次测量；重复发送时不修改采样时间。采样时间仅用于联调观察，不直接作为 ROS 时间戳；不回传累计位姿。

命令不逐帧应答，`last_seq` 仅表示最近接受的命令，不代表运动已完成。

## 5. 停车与恢复

- STM32 上电默认停车；急停或驱动故障时立即将目标速度清零。
- STM32 连续 **150 ms** 未收到有效命令时停车，置 `bit4`，并重新等待零速停车帧。
- 上电、通信超时或重连后，必须先接受新的零速停车帧，才允许运行；急停或故障须先解除并复位，再接收停车帧。
- 等待停车帧时丢弃运行帧，不更新目标、保活时间或 `last_seq`。接受停车帧后清除 `bit4`；正常状态下，接受的有效命令更新目标、保活时间和 `last_seq`。
- 上位机连续 **150 ms** 未收到有效状态帧时，持续发送零速停车帧。状态恢复后，确认停车帧已被接受、底盘就绪且无急停、故障或通信超时，再允许发送新的运动指令。
- `wz` 已包含上位机请求的底盘自旋，STM32 不再次叠加。

## 6. 编码样例

CRC16/MODBUS 按上述覆盖范围计算，低字节先发。

| 含义 | 完整十六进制帧 |
| --- | --- |
| 序号 1、零速停车 | `AA 55 02 10 01 00 07 00 00 00 00 00 00 00 70 DA` |
| 序号 2、运行、`vx=1.000 m/s`、`vy=-0.500 m/s`、`wz=0.200 rad/s` | `AA 55 02 10 02 00 07 01 E8 03 0C FE C8 00 F6 5D` |
| 反馈序号 1、就绪且使能、轮式速度有效、最近命令序号 2、实测 `vx=1.000 m/s`、`vy=-0.500 m/s`、`wz=0.200 rad/s`、采样时间 `123456 ms` | `AA 55 02 20 01 00 0E 23 00 02 00 E8 03 0C FE C8 00 40 E2 01 00 55 28` |
| 反馈序号 2、就绪且使能、轮式速度未启用/无效（`bit5=0`）、最近命令序号 2、速度与采样时间填 0 | `AA 55 02 20 02 00 0E 03 00 02 00 00 00 00 00 00 00 00 00 00 00 AE C0` |
