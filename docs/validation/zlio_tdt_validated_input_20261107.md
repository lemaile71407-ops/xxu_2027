## 2. NIS 与地图校正误差

独立从日志重建 `S=I+J P Jᵀ` 和 `NIS=rᵀS⁻¹r`，并核对原局部残差经平方根信息白化后的值。两轮日志的协方差及白化重建最大数值差均为 0。创新门保持原上尾概率 `<0.001`，使用实际自由度；本轮都是 6 维，未放宽门限。

“地图校正误差”在这里明确区分为：

- **地图测量误差**：scan-to-map 给出的测量位姿相对同时间真值的误差，包含被门拒绝的测量，不是配准内部点面残差 RMSE。
- **图预测误差**：加入本次地图观测之前的预测位姿相对真值的误差。
- **实际发布位姿误差**：`/localization/odometry` 相对真值的误差，包含现有冻结输出语义，不只统计已接受观测。

地图本来已处于固定场地坐标；首关键帧记录为 `(2,2,0.0725089)` m。评估按录得外参将真值模型位姿转换到同一虚拟传感器点，水平误差在世界 XY 平面计算，未作本轮轨迹对齐。

正确分支唯一一次 NIS 冲突出现在 **99.974575 s、runtime 144**：NIS **35.31084/6**，上尾概率约 **3.75×10⁻⁶**；预测水平误差 **10.73 cm**，地图测量水平误差 **5.58 cm**，随后短暂 OBS_DEGRADED。该例不能仅因地图测量更接近真值就称门控错误，也不能据此认定协方差已经校准。

正确分支地图测量水平误差 RMSE/P95/最大值为 **4.43/7.36/17.09 cm**；已接受测量的水平 RMSE 为 **4.42 cm**。NIS 总体来自几何准入后的相关样本，不能把均值、冲突比例或一条路线当成概率模型独立校准。

证据：[分析程序](data/zlio_tdt_validated_input_20261107/analyze.py)、[正确分支统计](data/zlio_tdt_validated_input_20261107/new01/analysis.json)、[逐次创新及测量](data/zlio_tdt_validated_input_20261107/new01/events.json)。

### 状态关联限制

实际状态多以 LiDAR 后验时间发布，高频全局里程计位于 IMU 时间，未得到一一同时间戳配对。主指标“全部发布位姿 RMSE”不依赖状态关联；可信/冻结子集采用 **0.5 s 内最新收到状态**，只作近似统计。正确分支关联年龄最大约 0.204 s；负对照另有 5 条无法按此方法分类，仍计入全部输出误差。

状态时长按投影时间及零时间戳心跳对应的回放时钟作单调近似，不是原子状态转换时钟。OBS_DEGRADED、SUSPECT、LOST 的消息数量、转换和时长均保存在结果中。该统计方法不构成位姿/状态发布协议验收。

## 6. 逐次全局校正效果

核验日期：2026-11-07。新增两次固定输入隔离回放，直接读取每次图更新返回值，按 `global correction committed` 逐条统计。**本节属于新的探针运行，不是对前文旧运行的 273/16 次提交补写优化结果**；前文原日志没有保存真实优化后位姿。新运行的正确输入分支有 274 次提交，旧点时间负对照有 124 次，分别全部配对成功，无缺项。

### 取值与比较口径

- 校正前：`FREEZE_DIAG_ABSOLUTE` 中实际图状态的 `predicted`，取自加入本次绝对观测之前；不使用更早的配准启动预测。
- 校正后：同一次 `PoseGraph::update(true)` 返回向量中**同一个 runtime 节点**的优化位姿。用 GDB 返回探针读取未修改二进制的内存，不把配准 `measured` 当成优化结果，也不借用附近时间的发布位姿。
- 真值：严格使用该节点的前端后验源时间；真值平移线性插值、旋转 SLERP，再乘录得的固定外参，得到同一虚拟传感器原点。不外推、不重新拟合地图与轨迹。
- 位置同时记录世界系 XY 距离和 XYZ 距离；航向使用 `atan2(R[1,0], R[0,0])`，差值折回 ±180°，比较其绝对值，区别于三维旋转角。
- `误差增量 = 校正后误差 − 校正前误差`，正值为变差。只对浮点舍入设平局容差：位置 10⁻⁹ m、航向 10⁻⁷°；另列大于 1 mm / 0.01° 的计数作幅度参考，均不改变业务门限。两侧本次均无平局。

原始图返回记录、提交日志字节位置、预测日志行号、runtime、epoch、前端序号、源时间、真值插值区间和三份完整 4×4 位姿均保留；CSV 另提供三份位置/航向、前后误差及增量。测量位姿也单独保留，避免混淆。

正确分支最后一次 **runtime 300、184.587160004 s** 已直接取得图优化结果，但在录得 TF 和上述高频里程计商中未确认其对应发布投影，故不声称该条已经完成输出转换验收，也不凭缺少样本认定转换错误。该条仍完整计入 274 次优化前后真值比较。

### 7.2 runtime 168 为什么被明显拉动

该次预测右局部平移标准差为 **24.64 / 25.04 / 24.43 mm**，测量为 **9.72 / 9.88 / 9.56 mm**。测量在平移上的置信度明显更强；旋转并非如此：预测旋转标准差 **0.088 / 0.097 / 0.091°**，测量 **0.207 / 0.262 / 0.154°**。

使用实际日志的 `P、J、r、S` 复算：

`δ = −P Jᵀ (I + J P Jᵀ)⁻¹ r`

得到的增量与图返回的实际增量，平移切向量只差 **0.416 μm**，旋转切向量只差 **0.0000104°**。因此，本次位移无需假设异常的 `map → odom` 转换或隐藏的大步优化即可解释。把测量信息按预测协方差归一化后，最强三个**混合模态**的融合增益为 **0.875 / 0.909 / 0.938**，不是三个世界坐标轴的独立系数。

| 世界系增量 | x | y | z |
| --- | ---: | ---: | ---: |
| 预测到测量 | −3.724 cm | −1.338 cm | −1.178 cm |
| 实际优化增量 | **−4.348 cm** | **−1.192 cm** | −0.057 cm |
| 预测到真值所需增量 | **+0.154 cm** | **+0.492 cm** | −0.822 cm |

保留测量相关项后，不能把优化理解为逐轴插值。按原始创新分解，旋转三项通过耦合贡献了世界平移约 **(−0.991, −0.023, +1.023) cm**，平移三项贡献 **(−3.356, −1.172, −1.079) cm**；它们的和复现优化位移。x 超过“预测到测量”的位移不意味着某个标量增益大于 1，而是多维相关项共同作用。

本次 NIS 为 **9.659/6，p≈0.140**，通过原门限。代码中 NIS 是接受/拒绝门，通过后按原平方根信息插入绝对位姿因子，**不再按 p 值软降权**。点面配准中的 Huber 阈值是 0.25 m；这四次最终对应均无点被 Huber 降权，因此它也没有减轻本次地图观测的影响力。

以 `e_Z = Log(Z⁻¹ T_truth)` 和实际测量信息 `I_Z=LᵀL` 计算六维 `NEES_Z=e_Zᵀ I_Z e_Z`，预测则用自身右局部误差及 `P⁻¹` 计算。以下误差都来自同一源时间，没有重新对齐。

三次大幅改善事件说明另一面：地图测量虽比预测更接近真值，其自身仍有 4.7–8.0 cm 水平误差；对应预测协方差也不能很好解释真值误差。四次测量世界系 x 误差均为负。这些事实支持继续核对偏差与相关性，而不能把“大幅改善”当成信息矩阵已校准。

源点数、有效对应数及原 36 扇区覆盖数全部与日志一致；点面 RMSE 的重建差最大 **2.73×10⁻⁸ m**。按对应重建原 Hessian，再施加 `1/5` 帧数信息预算、残差方差和共模协方差，所得实际测量信息矩阵与日志矩阵的相对 Frobenius 差最大 **8.30×10⁻⁷**。这是数值重建，不声称与运行时 PCL 点序逐字节相同。

信息生成并未忽略已有保护：残差方差为 `max(0.03², RMSE²·N/(N−6))`，原始信息为 `H/(5·variance)`，再在测量右局部坐标加入 **5 mm / 0.02°** 共模标准差。上述取值已在重建中包含，不能再把问题归结为“完全没做帧数折扣或共模地板”。

runtime 168 的 546 个有效对应中：

- 290 个来自近水平面（`|normal_z|>0.9`），提供 z 平移 Hessian 对角信息的 **85.6%**，但 x 方向仅 **1.5%**。
- 126 个来自近垂直面（`|normal_z|<0.2`），提供 x/y 方向约 **64.5% / 50.4%**。
- 130 个来自斜面，补充 x/y 方向约 **34.0% / 48.7%**。

因此水平影响力有可复现的局部几何来源，并非仅因地面点多或代码误把覆盖当成信息。覆盖仍有限：源点 z 中位数约 −6.3 cm，95 分位约 29.7 cm；20/36 扇区有对应，分布不均。局部满秩和高支持率不能检验地图与源云之间的系统性偏差。

更直接的反例是 runtime 168 的点面目标本身：原测量对应固定时，**真值位姿 RMSE 为 4.579 cm，而错误测量位姿为 3.060 cm**；允许重新关联时分别为 **4.483 / 3.060 cm**。三个改善事件也均出现“真值的点面 RMSE 高于测量位姿”。当前点面代价偏好的中心与真值存在差异，而局部 Hessian、残差缩放和 5 mm 地板没有充分表达这种差异。

runtime 168 虽达到 16 次迭代预算，原诊断显示最终剩余步长仅 **0.251 mm / 0.0127°**；不以“跑满预算”直接认定未收敛，也不据此增加迭代或调门限。下一步应优先区分固定地图与源几何的偏差、各帧累计误差及观测间相关性，再决定是否需要改测量模型或其不确定度；本节未实施这些修改。
