# RGL 逐点时间候选链验证（2026-10-31）

## 结论

**整套定位与导航仍未通过完整验证，不应替换正式导航链。** RGL 逐点时间、固定外参、ZLIO 前端及 `odom → base_footprint` 可以在受控仿真中工作；可选点云出口已接通 `/cloud_deskewed → /scan`，定位失信及超时门控有隔离试验证据。2026-11-01 已按用户要求开展正常输入下的 Nav2 闭环，并把先验图后端接入隔离候选：单目标通过，长路线出现错误恢复，开启已有连续性保护后能停车但导航未完成，当前结果统一见[后端正常导航复核](zlocalization_comparison_20261030.md#后端接入与正常导航复核2026-11-01)。下文的主动 IMU 中断测试保留为历史证据，当前正常运行不注入断流。此前的参数改善和保护候选均不能视为根因修复，正式默认仍保留旧链。

本次使用 ROS 2 Jazzy、无界面 Gazebo、RMUL 场地、EGA 固定雷达车型及隔离 ROS 域。RGL 使用 [逐点时间候选补丁](../../xxu_nav_2026/tools/navigation/rgl_timed_scan.patch)，前后端使用 `src/z-localization` 当前源码；前端、后端与适配器分别独立构建，ROS 消息依赖沿用本地已安装版本。点云时序是均匀射线顺序的仿真假设，并非实测 MID-360 时间；后端先验图取自同一仿真场地的历史录包构建图，当前仿真输入是新运行，不是独立场地图。未覆盖实车、动态云台或长时间运行。

2026-11-06 补充边界：后续独立路线 `capture03` 的实际点时间与 uniform 配置意图不一致，不能由本页早期候选能力验证推定其运行输入已保留逐点时间。原包及产物对照见[输入点时间溯源](zlio_input_point_time_trace_20261106.md)；新的[端到端时间与误差实验](zlio_point_time_e2e_20261106.md)已验证交付并显示同源改善，但未复现原 46.56 cm，不能认定原故障修复。

## 时间与底盘 TF

- RGL 的静止、线速度和角速度射线最小场景，以及带非零位置和 90° 方向的速度坐标系场景复测通过；点云整形器对时间字段、过滤和字节序的检查，以及底盘适配器 3 项测试通过。测试程序见[此前记录](rgl_point_timing_20261031.md)。
- 静止观察中 447 帧补偿点云都有多个点时间；观察到 4403 条 IMU、3413 组前端里程计、底盘里程计和底盘 TF。444 帧的采样区间落在观察到的 IMU 时间范围内，另 3 帧位于采样窗口边缘；该观察端记录的 IMU 最大间隔为 210 ms，不能判断是否发生源缺口。[结果](data/rgl_full_20261031/stationary_prior.json)。
- 随后用更深的接收队列同时观察原始 IMU 和补偿 IMU 40 秒：共同窗口的 3885 个时间戳全部一致，两路最大间隔均为 10 ms；没有再次观察到大间隔。这支持但不能单独证明前一次缺口来自观察端漏收。[结果](data/rgl_full_20261031/imu_comparison.json)。
- 静止的 3413 组、以及受控运动的 4653 组同时间戳数据中，传感器到车体的重算结果与底盘里程计最大平移差均小于 `5e-17 m`，旋转差为零；底盘消息与 `odom → base_footprint` TF 相同。固定变换 `lio_base_sensor ← base_footprint` 的 z 平移为 −0.069738 m。成功查询到 `map → base_footprint`，但仅证明边可查询，不证明后端位姿可信。[静止结果](data/rgl_full_20261031/stationary_prior.json)、[运动结果](data/rgl_full_20261031/motion_prior.json)。
- 对直行和旋转测试，暂停隔离仿真中的安全门并直接发送低速测试命令。首次直行真值与 ZLIO 水平位移分别约 1.3417 m、1.3416 m；首次旋转的航向变化分别约 2.36352 rad、2.36345 rad。运动观察窗口中底盘里程计与真值经首次平面位置和航向对齐，水平误差 RMS 约 2.65 mm、最大约 8.93 mm；该数值是相对轨迹结果，不是绝对定位或导航误差。[直行](data/rgl_full_20261031/straight.json)、[旋转](data/rgl_full_20261031/yaw.json)、[观测](data/rgl_full_20261031/motion_prior.json)。
